# AI Agent Flows

Use this folder to capture runbooks, prompts, or session summaries when agents tackle multi-step tasks.

Suggested pattern:

1. Create a dated subfolder (e.g., `2026-05-16-grade5-polish/`).
2. Drop Markdown notes or JSON instructions describing goals, decisions, and follow-ups.
3. Link back to relevant docs (project README, agent guide, flow plans) so future agents can pick up the thread quickly.
4. After saving the note, add a bullet to the “Recent Updates” list in [docs/README.md](../docs/README.md).

Keeping these notes current helps new agents understand context without re-reading entire transcripts.
