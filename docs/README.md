## How to Update Docs

1. Log every session in `ai_agent_flows/YYYY-MM-DD-title.md` (see README there for the template).
2. Update this index with any new documents or major changes.
3. Keep [agent/AGENT_GUIDE.md](agent/AGENT_GUIDE.md) and [flows/plan.md](flows/plan.md) aligned with parser or pipeline updates.
4. Note significant structural changes in the root README under “Documentation & Agent Guides.”
